Topic 1: Why Worker Threads?

Code Example
import { Worker } from 'worker_threads';
Explanation

Worker Threads run CPU-intensive tasks on separate threads so the Event Loop stays responsive.

Interview Question
When should Worker Threads be used?
Expected Answer
For CPU-bound work such as image processing or heavy calculations.

Topic 2: Creating a Worker

Code Example
const worker = new Worker('./worker.js');
Explanation

A Worker executes another JavaScript file in parallel.

Interview Question
How do you create a Worker?
Expected Answer
Using the Worker class from worker_threads.

Topic 3: Communicating with Workers

Code Example
worker.postMessage(data);
worker.on('message',(msg)=>{});
Explanation

The main thread and worker exchange messages.

Interview Question
How do Workers communicate?
Expected Answer
Using postMessage() and the message event.

Topic 4: workerData

Code Example
new Worker('./worker.js',{ workerData:{ n:100 } });
Explanation

Pass initial data to a worker when it starts.

Interview Question
How do you send startup data?
Expected Answer
Using the workerData option.

Topic 5: parentPort

Code Example
parentPort.postMessage(result);
Explanation

Inside the worker, parentPort sends data back to the main thread.

Interview Question
How does a worker return results?
Expected Answer
Using parentPort.postMessage().

Topic 6: Cluster Module

Code Example
import cluster from 'cluster';
Explanation

Cluster creates multiple Node.js processes to utilize multiple CPU cores.

Interview Question
Why use Cluster?
Expected Answer
To improve throughput by using all CPU cores.

Topic 7: Worker Threads vs Cluster

Code Example
Worker Threads share one process.
Cluster creates separate processes.
Explanation

Workers are ideal for CPU tasks; Cluster is ideal for scaling HTTP servers.

Interview Question
Difference between Worker Threads and Cluster?
Expected Answer
Workers = threads, Cluster = processes.

Topic 8: CPU Count

Code Example
import os from 'os';
const cores=os.cpus().length;
Explanation

Use available CPU cores when creating cluster workers.

Interview Question
How do you get CPU core count?
Expected Answer
os.cpus().length.

Topic 9: Error Handling

Code Example
worker.on('error',err=>console.error(err));
Explanation

Always listen for worker errors and exits.

Interview Question
Why handle worker errors?
Expected Answer
To prevent silent failures.

Topic 10: Best Practices

Code Example
// Use workers only for heavy CPU work
Explanation

Avoid Workers for simple I/O tasks because Node already handles I/O efficiently.

Interview Question
Should every task use Worker Threads?
Expected Answer
No, only CPU-intensive tasks.

Quick Revision

  • Worker Threads are for CPU-intensive tasks.
  • Cluster uses multiple Node.js processes to utilize CPU cores.
  • Workers communicate using postMessage() and parentPort.
  • Use workerData to pass startup data.
  • Use os.cpus().length to determine available cores.
  • Always handle worker error and exit events.
  • Don't use Worker Threads for normal I/O operations.
