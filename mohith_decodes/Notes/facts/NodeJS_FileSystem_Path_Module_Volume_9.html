Topic 1: fs.readFile() vs fs.readFileSync()

Code Example
await fs.promises.readFile('data.txt','utf8');

const data = fs.readFileSync('data.txt','utf8');
Explanation

readFile() is asynchronous and doesn't block the Event Loop. readFileSync() blocks execution until the file is completely read.

Interview Question
Which one is preferred in production APIs?
Expected Answer
The asynchronous version.

Topic 2: writeFile()

Code Example
await fs.promises.writeFile('notes.txt','Hello Node.js');
Explanation

Creates a new file or overwrites an existing file.

Interview Question
What happens if the file already exists?
Expected Answer
Its contents are overwritten.

Topic 3: appendFile()

Code Example
await fs.promises.appendFile('logs.txt','New Log\n');
Explanation

Adds new content to the end of an existing file.

Interview Question
When should appendFile() be used?
Expected Answer
For logs and incremental writes.

Topic 4: unlink()

Code Example
await fs.promises.unlink('old.txt');
Explanation

Deletes a file from the file system.

Interview Question
Which method deletes a file?
Expected Answer
unlink().

Topic 5: mkdir()

Code Example
await fs.promises.mkdir('uploads',{recursive:true});
Explanation

Creates a directory. recursive:true also creates missing parent folders.

Interview Question
What does recursive:true do?
Expected Answer
Creates nested folders if needed.

Topic 6: existsSync()

Code Example
if(fs.existsSync('uploads')){
 console.log('Folder exists');
}
Explanation

Checks whether a file or folder exists synchronously.

Interview Question
When is existsSync() useful?
Expected Answer
Before creating or deleting files/folders.

Topic 7: createReadStream()

Code Example
const stream = fs.createReadStream('movie.mp4');
Explanation

Reads large files chunk by chunk instead of loading them entirely into memory.

Interview Question
Why use createReadStream()?
Expected Answer
To reduce memory usage.

Topic 8: path.join()

Code Example
const filePath = path.join(__dirname,'uploads','image.png');
Explanation

Safely joins path segments using the correct OS separator.

Interview Question
Why use path.join()?
Expected Answer
To create cross-platform file paths.

Topic 9: path.extname()

Code Example
const ext = path.extname('photo.jpg');
Explanation

Returns the file extension including the leading dot.

Interview Question
What does path.extname() return?
Expected Answer
The file extension.

Topic 10: path.basename()

Code Example
const name = path.basename('/images/logo.png');
Explanation

Returns only the file name from a full path.

Interview Question
What does basename() return?
Expected Answer
The file name.

Topic 11: path.dirname()

Code Example
const dir = path.dirname('/images/logo.png');
Explanation

Returns the directory portion of a path.

Interview Question
What does dirname() return?
Expected Answer
The directory path.

Topic 12: Best Practices

Code Example
try {
 await fs.promises.readFile('data.txt');
} catch(err){
 console.error(err);
}
Explanation

Prefer fs/promises with async/await, handle errors, and use path.join() instead of hardcoded separators.

Interview Question
What is the recommended way to use the fs module?
Expected Answer
Use fs/promises with async/await.

Quick Revision

  • Prefer asynchronous fs methods in production.
  • Use fs/promises with async/await.
  • readFileSync() blocks the Event Loop.
  • Use createReadStream() for large files.
  • Use path.join() for cross-platform compatibility.
  • Use path.extname(), basename(), and dirname() to work with file paths.
  • Always wrap file operations in try...catch.
