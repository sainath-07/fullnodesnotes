Behavior 1: Middleware Executes in Order

Code Example
app.use(logger);
app.use(auth);
app.use(routes);
Explanation

Express executes middleware in the exact order they are registered.

Interview Question
Why does middleware order matter?
Expected Answer
Requests flow top-to-bottom through registered middleware.

Behavior 2: next() Doesn't Stop Execution

Code Example
app.use((req,res,next)=>{
  console.log('A');
  next();
  console.log('B');
});
Explanation

Code after next() still executes unless you return.

Interview Question
What is the benefit of return next()?
Expected Answer
It prevents accidental execution of code after next().

Behavior 3: return res.json()

Code Example
if(!user){
  return res.status(404).json({message:'Not found'});
}
console.log('Runs only if user exists');
Explanation

Returning avoids sending multiple responses.

Interview Question
Why use return with res.json()?
Expected Answer
To stop the current function.

Behavior 4: Error Middleware Has Four Parameters

Code Example
app.use((err,req,res,next)=>{
 res.status(500).json({message:err.message});
});
Explanation

Express recognizes error handlers only when they have four parameters.

Interview Question
Why include next if unused?
Expected Answer
It identifies the function as error middleware.

Behavior 5: Route Matching Order

Code Example
app.get('/login',login);
app.get('/:id',user);
Explanation

Static routes should come before dynamic routes.

Interview Question
Why can /:id capture /login?
Expected Answer
Because Express matches routes in declaration order.

Behavior 6: express.json()

Code Example
app.use(express.json());
Explanation

Without it, JSON request bodies are not parsed.

Interview Question
Why is req.body undefined?
Expected Answer
JSON parser middleware is missing.

Behavior 7: Router is Mini App

Code Example
const router=express.Router();
router.get('/users',handler);
Explanation

Routers help organize related endpoints.

Interview Question
Why use express.Router()?
Expected Answer
To keep code modular and maintainable.

Behavior 8: Headers Already Sent

Code Example
res.json({ok:true});
// res.json({again:true});
Explanation

Sending two responses throws 'Cannot set headers after they are sent'.

Interview Question
What causes 'headers already sent'?
Expected Answer
Sending more than one response.

Behavior 9: Async Errors

Code Example
try{
 await work();
}catch(err){
 next(err);
}
Explanation

Forward async errors to centralized error handling.

Interview Question
How should async route errors be handled?
Expected Answer
Pass them to next(err).

Behavior 10: app.use() vs app.METHOD()

Code Example
app.use('/api',router);
app.get('/users',handler);
Explanation

app.use() registers middleware; app.get/post/etc. register route handlers.

Interview Question
When should you use app.use()?
Expected Answer
For middleware or mounting routers.

Quick Revision

  • Middleware runs in registration order.
  • Use return res.json() to stop execution.
  • Always place static routes before dynamic routes.
  • Register express.json() before routes.
  • Error middleware must have four parameters.
  • Use express.Router() for modular routing.
