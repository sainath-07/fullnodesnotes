Important: Exact ordering involving timers and setImmediate() can depend on where the code runs. Always identify whether the code is inside an I/O callback.
Quick Recap — Interview Ready
  • nextTick: Node-specific queue with very high priority; excessive use can starve I/O.
  • Promise callbacks / queueMicrotask: microtasks that run after the current synchronous work.
  • setImmediate: check phase; especially useful after I/O callbacks.
  • Streams: process data in chunks instead of loading everything into memory.
  • Backpressure: slow the producer when the consumer cannot keep up.
  • EventEmitter: synchronous listener execution by default; listener management matters.
  • Workers: CPU-heavy JavaScript work; not a replacement for normal async I/O.
  • Cluster: multiple Node processes; useful for using multiple CPU cores.
  • Graceful shutdown: stop accepting work, finish active work, close resources, then exit.
  • Express middleware: order matters; next() controls movement through the chain.
Strong interview answer: State the output → explain the execution order → mention an important edge case → give a production use case.
