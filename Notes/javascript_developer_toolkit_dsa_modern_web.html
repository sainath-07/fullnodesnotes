1. What This Guide Is About

Small JavaScript techniques that create big advantages

When learning DSA or building software, you often discover that the hard part is not the algorithm itself. Knowing the language well can make the algorithm much shorter and easier to express.

Example: Instead of creating a temporary variable for swapping two array elements, JavaScript supports destructuring assignment.
let temp = nums[i];
nums[i] = nums[maxIndex];
nums[maxIndex] = temp;

// Modern JavaScript
[nums[i], nums[maxIndex]] = [nums[maxIndex], nums[i]];
DSA idea ↓ Algorithm ↓ JavaScript language feature ↓ Shorter + clearer implementation Example: "swap two values" ↓ destructuring assignment ↓ [a, b] = [b, a]

Goal: Don't memorize tricks blindly. Learn what problem each feature solves and when it is appropriate.

2. Swapping & Multiple Assignment
2.1 Swap two variables
let a = 10;
let b = 20;

[a, b] = [b, a];

console.log(a); // 20
console.log(b); // 10

Why useful? Selection sort, two pointers, reversing arrays, partitioning, matrix problems.

2.2 Swap array elements
[nums[i], nums[j]] = [nums[j], nums[i]];
2.3 Rotate variables
let a = 1, b = 2, c = 3;

[a, b, c] = [b, c, a];

// a=2, b=3, c=1
Remember: Destructuring is elegant, but don't use clever syntax if it makes the code harder for your team to understand.
3. Array Techniques You Should Know
3.1 Destructuring an array
const nums = [10, 20, 30];

const [first, second, third] = nums;
3.2 Ignore values
const [first, , third] = [10, 20, 30];
3.3 Rest operator
const [first, ...remaining] = [10, 20, 30, 40];

// first = 10
// remaining = [20, 30, 40]
3.4 Spread operator
const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b];
// [1, 2, 3, 4]
3.5 Remove without mutating the original
const nums = [10, 20, 30, 40];

const result = nums.filter(x => x !== 30);
3.6 Get last element
const last = nums.at(-1);

Useful when the index is relative to the end.

3.7 Get first/last without manual indexes
const first = nums.at(0);
const last = nums.at(-1);
3.8 Fill an array
const zeros = new Array(5).fill(0);
// [0, 0, 0, 0, 0]
3.9 Create a sequence
const nums = Array.from({ length: 5 }, (_, i) => i);
// [0, 1, 2, 3, 4]
3.10 Convert iterable values to arrays
const chars = Array.from("hello");
// ["h", "e", "l", "l", "o"]
3.11 Flatten nested arrays
const nums = [1, [2, 3], [4, [5]]];

nums.flat();
// [1, 2, 3, 4, [5]]

nums.flat(Infinity);
// [1, 2, 3, 4, 5]
3.12 Find an object
const users = [
  { id: 1, name: "A" },
  { id: 2, name: "B" }
];

const user = users.find(user => user.id === 2);
3.13 Check whether an item exists
nums.includes(10);
3.14 Check a condition across an array
nums.some(x => x > 100);
nums.every(x => x >= 0);
DSA connection: at(), includes(), find(), some(), every(), flat(), Array.from(), spread and destructuring appear frequently in clean implementations.

const { name, age } = user;

4.5 Object.entries()
const user = { name: "A", age: 30 };

for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
4.6 Object.keys() and Object.values()
Object.keys(user);
Object.values(user);

Real product use: Object spread is common when creating updated React state, configuration objects, API payloads and immutable transformations.
5. Map & Set — Extremely Useful for DSA
5.1 Set — remove duplicates
const nums = [1, 2, 2, 3, 3, 4];

const unique = [...new Set(nums)];
// [1, 2, 3, 4]
5.2 Set — fast membership checking
const seen = new Set();

seen.add(10);
seen.has(10); // true
seen.delete(10);

Average lookup is generally O(1).

5.3 Map — key/value storage
const map = new Map();

map.set("apple", 10);
map.set("banana", 20);

map.get("apple");
map.has("banana");
5.4 Frequency counter
const freq = new Map();

for (const num of nums) {
  freq.set(num, (freq.get(num) ?? 0) + 1);
}
5.5 Two Sum pattern
const seen = new Map();

for (let i = 0; i < nums.length; i++) {
  const needed = target - nums[i];

  if (seen.has(needed)) {
    return [seen.get(needed), i];
  }

  seen.set(nums[i], i);
}
Array search: [5, 9, 2, 7, 4] ↓ find 7? ↓ scan → scan → scan O(n) Set / Map: value → lookup 7 → true approximately O(1) average lookup
Interview rule: If you repeatedly ask “Have I seen this before?”, immediately consider Set or Map.
6. String Techniques
6.1 Convert string to characters
const chars = [..."hello"];
6.2 Reverse a simple string
const reversed = [...str].reverse().join("");
For Unicode text such as some emoji sequences, simple character reversal can be more complicated than this. Use this technique mainly for normal interview-style strings.
6.3 Check palindrome
const reversed = [...str].reverse().join("");

if (str === reversed) {
  // palindrome
}
6.4 Split into words
const words = sentence.trim().split(/\s+/);
6.5 String search
str.includes("cat");
str.startsWith("Hello");
str.endsWith("!");
6.6 Character code
"A".charCodeAt(0); // 65

String.fromCharCode(65); // "A"
6.7 Repeat
"*".repeat(5);
// *****

Useful for pattern-printing questions.

7. Modern JavaScript Features Worth Knowing
7.1 Optional chaining
const city = user?.address?.city;

Instead of manually checking every level.

7.2 Nullish coalescing
const count = value ?? 0;

Uses 0 only when the value is null or undefined.

7.3 Difference: || vs ??
0 || 10   // 10
0 ?? 10   // 0

"" || "x" // "x"
"" ?? "x" // ""
Remember: Use ?? when you specifically mean “missing value”. Use || when you mean “falsy value”.
7.4 Logical assignment
value ||= 10; // assign if falsy
value ??= 10; // assign if null/undefined
value &&= 10; // assign if truthy
7.5 Default function parameters
function greet(name = "Guest") {
  return `Hello ${name}`;
}
7.6 Rest parameters
function sum(...nums) {
  return nums.reduce((total, n) => total + n, 0);
}
7.7 Null-safe method call
const result = value?.toString();
7.8 Structured cloning
const copy = structuredClone(original);

Useful for deep-copying many structured data types. It is different from shallow spread copying.

Important: {...obj} and [...arr] create shallow copies. Nested objects/arrays remain shared.

9.1 Numeric sort — common JavaScript trap
[10, 2, 5].sort();
// [10, 2, 5]  ← lexicographic/string-like ordering

[10, 2, 5].sort((a, b) => a - b);
// [2, 5, 10]
9.2 Descending
nums.sort((a, b) => b - a);
9.3 Stack with an array
const stack = [];

stack.push(10);
stack.push(20);

const top = stack.pop();
9.4 Queue without shift()
const queue = [10, 20, 30];
let head = 0;

while (head < queue.length) {
  const value = queue[head++];
  console.log(value);
}
Why? Repeatedly removing the first element with shift() can cause unnecessary work for large arrays. A head index is a common interview-friendly queue technique.
10. Math & Bitwise Tricks — Useful, But Don't Overuse Them
10.1 Check even / odd
if (n % 2 === 0) {
  // even
}
10.2 Power of two
n > 0 && (n & (n - 1)) === 0

This works because powers of two have exactly one set bit in binary.

10.3 XOR for toggling bits
let mask = 0;

mask ^= 1; // toggle lowest bit
10.4 XOR swap — know it, but don't prefer it
a ^= b;
b ^= a;
a ^= b;
Interview note: JavaScript destructuring is much clearer. Know XOR swap as a concept, not as your normal production technique.
10.5 Integer truncation — don't use bitwise tricks casually
Math.floor(5.9); // 5

Modern JavaScript code should generally prefer readable numeric APIs instead of old bitwise truncation tricks.

  ...user,
  name: "New Name"

Common in state management and predictable UI updates.

Optional API data
const name =
  response?.data?.user?.name ?? "Unknown";

Useful when API responses can have missing fields.

Configuration merging

  ...defaultConfig,
  ...userConfig
};

Useful for defaults and overrides.

Transform API data
const cards = users.map(user => ({
  id: user.id,
  title: user.name
}));

Convert backend data into UI-friendly structures.

Fast lookup cache
const cache = new Map();

cache.set(id, data);
const result = cache.get(id);

Useful for caching and avoiding repeated work.

Deduplicate IDs
const uniqueIds = [...new Set(ids)];

Useful when processing events, API data, tags or selections.

12. Things Developers Often Learn Too Late
  1. Know the data structure before coding. Many slow solutions become fast by changing Array → Set/Map.
  2. Understand mutation. sort(), reverse(), push(), pop(), splice() mutate the array.
  3. Understand shallow vs deep copy. Spread syntax does not deeply clone nested objects.
  4. Don't use shift() repeatedly for large queues. Use a head pointer.
  5. Don't assume sort() is numeric. Supply a comparator.
  6. Know Big-O of your operations. Short code can still be slow code.
  7. Use Map/Set intentionally. They can turn repeated searches into much faster lookups.
  8. Readable code beats clever code. A one-line trick is not automatically better.
  9. Learn the language and DSA together. Algorithmic thinking tells you what to do; language knowledge tells you how to express it efficiently.
Best mindset: When you learn a new JavaScript feature, ask: “What problem does this remove?” That is much more useful than memorizing syntax.

14. Final Mental Model
When solving a DSA problem: 1. Understand the problem ↓ 2. Pick the right data structure ↓ 3. Think about time + space complexity ↓ 4. Look for a known pattern ↓ 5. Use JavaScript features to express the solution cleanly Examples: "Need to swap?" → destructuring "Have I seen this?" → Set "Need value → index?" → Map "Need to transform?" → map() "Need to keep matching values?" → filter() "Need one final result?" → reduce() "Need optional nested data?" → ?. "Need a default only for null/undefined?" → ?? "Need queue?" → array + head index "Need numeric sort?" → sort((a,b) => a-b)
The bigger goal: Become the developer who can look at a problem and quickly recognize both the algorithmic pattern and the language tool that fits it.
