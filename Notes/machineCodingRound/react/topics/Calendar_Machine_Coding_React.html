2. What Problem Does It Solve?
  • View dates by month.
  • Navigate previous/next months.
  • Identify today.
  • Select a date.
  • Provide a base for booking, scheduling, reminders and events.
Interview insight: Calendar tests React state, JavaScript Date handling, array generation, conditional rendering, event handling and edge-case thinking.
3. Requirements
  1. Display month and year.
  2. Display weekday headers.
  3. Generate the correct days dynamically.
  4. Align day 1 under the correct weekday.
  5. Previous/next month navigation.
  6. Highlight today.
  7. Select a date.
  8. Highlight selected date.
  9. Optional Today button.
Strategy: Build monthly view and navigation first, then selection. Add events, ranges or recurrence only if requested.
4. State Design

Keep only the minimum state. The calendar cells are derived data.

const [currentDate, setCurrentDate] = useState(new Date());
const [selectedDate, setSelectedDate] = useState(null);
  • currentDate = month currently displayed.
  • selectedDate = date chosen by user.
Important: Do not store year, month, days count and the entire grid separately. Most of those are derived from currentDate.
5. How Does It Work?
1. Get year and month
const year = currentDate.getFullYear();
const month = currentDate.getMonth();

January is 0 and December is 11.

2. Find weekday of first day
const firstDay = new Date(year, month, 1);
const startDay = firstDay.getDay();

getDay(): Sunday = 0 through Saturday = 6.

3. Find days in month
const daysInMonth = new Date(year, month + 1, 0).getDate();

The day 0 means the last day of the previous month.

4. Generate cells

Add empty cells for the starting weekday, then add 1 through daysInMonth.

5. Navigate
setCurrentDate(new Date(year, month - 1, 1)); // previous
setCurrentDate(new Date(year, month + 1, 1)); // next
6. Date Calculation — Most Important Logic
// First day
new Date(year, month, 1)

// Weekday of first day
new Date(year, month, 1).getDay()

// Days in current month
new Date(year, month + 1, 0).getDate()
Example: October 2026
year = 2026
month = 9

firstDay = new Date(2026, 9, 1)
startDay = firstDay.getDay()

daysInMonth = new Date(2026, 10, 0).getDate()
             = 31

If the first day is Thursday:

Interview trick: Remember new Date(year, month + 1, 0).getDate() for days in a month.

9. Full React Code

Calendar.jsx

import { useMemo, useState } from "react";
import "./Calendar.css";

const weekDays = ["Sun","Mon","Tue","Wed","Thu","Fri","Sat"];

function Calendar() {
  const [currentDate, setCurrentDate] = useState(new Date());
  const [selectedDate, setSelectedDate] = useState(null);

  const year = currentDate.getFullYear();
  const month = currentDate.getMonth();

  const monthName = currentDate.toLocaleString("default", {
    month: "long"
  });

  const days = useMemo(() => {
    const firstDay = new Date(year, month, 1);
    const startDay = firstDay.getDay();

    const daysInMonth =
      new Date(year, month + 1, 0).getDate();

    const cells = [];

    for (let i = 0; i < startDay; i++) {
      cells.push(null);
    }

    for (let day = 1; day <= daysInMonth; day++) {
      cells.push(day);
    }

    return cells;
  }, [year, month]);

  function goToPreviousMonth() {
    setCurrentDate(new Date(year, month - 1, 1));
  }

  function goToNextMonth() {
    setCurrentDate(new Date(year, month + 1, 1));
  }

  function goToToday() {
    setCurrentDate(new Date());
  }

  function handleDateClick(day) {
    if (!day) return;

    const date = new Date(year, month, day);
    setSelectedDate(date.toDateString());
  }

  function isToday(day) {
    if (!day) return false;

    const today = new Date();

    return (
      today.getFullYear() === year &&
      today.getMonth() === month &&
      today.getDate() === day
    );
  }

  function isSelected(day) {
    if (!day || !selectedDate) return false;

    const selected = new Date(selectedDate);

    return (
      selected.getFullYear() === year &&
      selected.getMonth() === month &&
      selected.getDate() === day
    );
  }

}

From currentDate, I calculate the year, month, weekday of the first day, and number of days in that month. I generate the calendar cells dynamically instead of hard-coding dates.

The previous and next buttons update currentDate, which causes React to re-render and calculate the new month's grid. I also highlight today's date, allow date selection, and provide a Today button. 12. Common Developer Mistakes
1. Hard-coding dates: February and different month lengths make hard-coded calendars unreliable.
2. Forgetting getMonth() is zero-based:
January = 0
February = 1
...
December = 11
3. Confusing getDay() and getDate():
  • getDay() → weekday 0–6
  • getDate() → day of month 1–31
4. Hard-coding 30/31 days: Use new Date(year, month + 1, 0).getDate().
5. Forgetting leading empty cells: If day 1 is Thursday, four positions are needed before it when Sunday is the first column.
6. Too much state: Don't store year, month, days count, first weekday and the entire grid separately.
7. Comparing Date objects with ===: Date objects are references. Compare normalized year/month/day values instead.
8. Timezone bugs: Unnecessary UTC/ISO conversions can shift a date-only value by one day.
9. Missing keys: Generated cells need React keys.
10. Missing year transitions: January previous → December previous year; December next → January next year.

15. Interviewer Follow-up Questions
Q1. Why not store all calendar cells in state?

Because the grid is derived from the displayed month. Independent storage duplicates data and creates synchronization problems.

Q2. Why is January month 0?

JavaScript Date uses zero-based month indexes.

Q3. getDay() vs getDate()?

getDay() returns weekday 0–6; getDate() returns day of month 1–31.

Q4. How do you handle leap years?

The Date calculation handles them automatically.

Q5. How would you add events?

Store events as data such as { date, title, type }, then match each calendar day with event dates.

Q6. How would you support date ranges?

Store startDate and endDate, then check whether each cell falls between them.

Q7. How would you support Monday as first day?

Shift the weekday calculation so Monday becomes index 0.

Q8. Would you use a library?

For simple requirements native Date can work. For complex timezone, locale, recurrence or range requirements, a mature date library can reduce edge-case bugs.

Q9. Complexity?

Generating a month is O(D), where D is the number of displayed cells/days; for a normal month this is small and bounded.
