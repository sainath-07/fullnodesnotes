1. What is Tic-Tac-Toe?

Tic-Tac-Toe is a two-player game played on a 3 × 3 grid. One player uses X and the other uses O. Players take turns selecting empty cells. The first player to get three matching symbols horizontally, vertically, or diagonally wins.

  1. Display a 3 × 3 board.
  2. Start with X.
  3. Click an empty cell to place the current symbol.
  4. Alternate X and O turns.

8. Full React Code

App.jsx

import { useState } from "react";
import "./App.css";

const winningPatterns = [
  [0,1,2], [3,4,5], [6,7,8],
  [0,3,6], [1,4,7], [2,5,8],
  [0,4,8], [2,4,6]
];

function calculateWinner(board) {
  for (const [a,b,c] of winningPatterns) {
    if (
      board[a] &&
      board[a] === board[b] &&
      board[a] === board[c]
    ) {
      return board[a];
    }
  }
  return null;
}

function App() {
  const [board, setBoard] = useState(Array(9).fill(null));
  const [isXNext, setIsXNext] = useState(true);

  const winner = calculateWinner(board);
  const isDraw = !winner && board.every(Boolean);
  const currentPlayer = isXNext ? "X" : "O";

  function handleClick(index) {
    if (board[index] || winner) return;

    const newBoard = [...board];
    newBoard[index] = currentPlayer;

    setBoard(newBoard);

    // Do not switch after a winning move.
    if (!calculateWinner(newBoard)) {
      setIsXNext(!isXNext);
    }
  }

  function resetGame() {
    setBoard(Array(9).fill(null));
    setIsXNext(true);
  }

  function getStatus() {
    if (winner) return \`Winner: \${winner}\`;
    if (isDraw) return "Game Draw!";
    return \`Next Player: \${currentPlayer}\`;
  }

  return (
    <div className="game">
      <h1>Tic-Tac-Toe</h1>
      <h2>{getStatus()}</h2>

      <div className="board">
        {board.map((value, index) => (
          <button
            key={index}
            className="cell"
            onClick={() => handleClick(index)}
            disabled={Boolean(value) || Boolean(winner)}
            aria-label={\`Cell \${index + 1}\`}
          >
            {value}
          </button>
        ))}
      </div>

      <button className="reset" onClick={resetGame}>
        New Game
      </button>
    </div>
  );
}

export default App;

11. Common Developer Mistakes
1. Mutating state directly
board[index] = "X"; // ❌
setBoard(board);
const newBoard = [...board];
newBoard[index] = "X";
setBoard(newBoard); // ✅
2. Not blocking occupied cells

Without if (board[index]) return, players can overwrite moves.

3. Checking the old board

The latest move is in newBoard, so winner detection must use the updated board.

4. Forgetting draw detection

Use !winner && board.every(Boolean).

5. Allowing moves after winning

Return early or disable cells when a winner exists.

6. Writing eight separate winner conditions

Store winning patterns in an array and loop through them.

7. Switching turn after game over

Do not switch players after a winning move.

8. Incorrect indexes

Keep the 0–8 mapping clear and consistent.

14. Interviewer Follow-up Questions
Q1. Why an array of 9 instead of a 2D array?

A one-dimensional array is simple to render and makes winning combinations easy to represent using indexes.

Q2. Why copy the board?

React state should be treated as immutable. A new array makes updates predictable.

Q3. How many winning combinations?

Eight: 3 rows + 3 columns + 2 diagonals.

Q4. Time complexity of winner checking?

O(1) for a fixed 3×3 board because there are only 8 combinations.

Q5. How would you support N×N?

Generate winning combinations dynamically and evaluate rows, columns, and diagonals based on board size.

Q6. How add score tracking?

Maintain a separate score object such as {X: 0, O: 0} and increment the winner's score.

Q7. How add AI?

Use a random available move for basic AI, or Minimax for stronger play.

Q8. How make components reusable?

Split into Game, Board, and Cell, passing data and handlers through props.
