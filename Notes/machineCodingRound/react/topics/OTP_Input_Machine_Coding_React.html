What?

What is OTP Input?

An OTP Input is a UI component used to enter a One-Time Password, usually received through SMS, email, or an authenticator service.

Instead of using one large input, the OTP is commonly displayed as separate boxes. For example, a 6-digit OTP appears as:

Interview definition: “OTP Input is a controlled React component that manages multiple digit fields, handles focus movement, validates input, supports backspace and paste, and submits the OTP when all digits are entered.”
Why?

What problem does it solve?

Better UX

Users can visually understand exactly how many digits are required.

Fast entry

The component automatically moves focus after every digit.

Input control

It prevents invalid characters and limits each box to one digit.

Real-world authentication

It is commonly used in login verification, signup, payments, and password recovery.

Requirements

What should I implement?

  1. Render 6 individual input boxes.
  2. Allow only one numeric character in each box.
  3. Automatically focus the next input after typing.
  4. When Backspace is pressed on an empty box, focus the previous box.
  5. Support pasting a complete OTP.
  6. Show an error if the OTP is incomplete.
  7. Submit the complete OTP.
  8. Keep the inputs controlled through React state.
Machine coding tip: Build the basic typing + focus behavior first. Then add Backspace, paste, validation, and polish.
How?

How does it work?

The main idea is simple: keep all OTP digits in one state array and keep references to all input elements.

const [otp, setOtp] = useState(Array(length).fill(""));

const inputRefs = useRef([]);

otp = ["", "", "", "", "", ""]

When the user types a digit:

  1. Read the typed value.
  2. Keep only the last valid digit.
  3. Update the corresponding index in otp.
  4. Move focus to the next input.

Full Code

React OTP Input — Interview Version

This version covers typing, numeric validation, auto-focus, Backspace, arrow navigation, paste, and submission.

import { useRef, useState } from "react";

function OTPInput({ length = 6, onSubmit }) {
  const [otp, setOtp] = useState(Array(length).fill(""));
  const [error, setError] = useState("");

  const inputRefs = useRef([]);

  const focusInput = (index) => {
    if (index >= 0 && index < length) {
      inputRefs.current[index]?.focus();
    }
  };

  const handleChange = (e, index) => {
    const value = e.target.value;

    // Keep only digits.
    const digit = value.replace(/\D/g, "").slice(-1);

    if (!digit) return;

    const nextOtp = [...otp];
    nextOtp[index] = digit;
    setOtp(nextOtp);
    setError("");

    // Move focus forward.
    if (index < length - 1) {
      focusInput(index + 1);
    }
  };

  const handleKeyDown = (e, index) => {
    if (e.key === "Backspace") {
      if (otp[index]) {
        const nextOtp = [...otp];
        nextOtp[index] = "";
        setOtp(nextOtp);
      } else if (index > 0) {
        const nextOtp = [...otp];
        nextOtp[index - 1] = "";
        setOtp(nextOtp);
        focusInput(index - 1);
      }
    }

    if (e.key === "ArrowLeft") {
      focusInput(index - 1);
    }

    if (e.key === "ArrowRight") {
      focusInput(index + 1);
    }
  };

  const handlePaste = (e) => {
    e.preventDefault();

    const pasted = e.clipboardData
      .getData("text")
      .replace(/\D/g, "")
      .slice(0, length);

    if (!pasted) return;

    const nextOtp = Array(length).fill("");

    pasted.split("").forEach((digit, index) => {
      nextOtp[index] = digit;
    });

    setOtp(nextOtp);

    const nextFocus = Math.min(pasted.length, length - 1);
    focusInput(nextFocus);
  };

  const handleSubmit = (e) => {
    e.preventDefault();

    if (otp.some((digit) => digit === "")) {
      setError(`Please enter all ${length} digits.`);
      return;
    }

    const finalOtp = otp.join("");
    setError("");
    onSubmit?.(finalOtp);
  };

  return (
    <form onSubmit={handleSubmit}>
      <div className="otp-container">
        {otp.map((digit, index) => (
          <input
            key={index}
            ref={(el) => (inputRefs.current[index] = el)}
            value={digit}
            maxLength={1}
            inputMode="numeric"
            autoComplete="one-time-code"
            onChange={(e) => handleChange(e, index)}
            onKeyDown={(e) => handleKeyDown(e, index)}
            onPaste={handlePaste}
            aria-label={`OTP digit ${index + 1}`}
          />
        ))}
      </div>

      {error && <p className="error">{error}</p>}

      <button type="submit">Verify OTP</button>
    </form>
  );
}

export default OTPInput;

Interview Answer

How to explain in 1 minute

“I built the OTP input as a controlled React component. I store all OTP digits in an array state, for example ["4","8","","","",""]. I create multiple input boxes and store their DOM references using useRef. When the user enters a digit, I update the corresponding state index and automatically focus the next input. For Backspace, if the current box is empty, I move focus to the previous box. I also handle paste by reading the clipboard, extracting digits, and distributing them across the inputs. Finally, before submission I check that every position is filled and combine the array using join("") to get the final OTP.”
Interview Answer

How to explain in 5 minutes

  1. Requirement: “The user needs to enter a fixed-length OTP, one digit per box.”
  2. State: “I use an array because every input corresponds to one index.”
  3. Refs: “I use useRef to store each input DOM element so I can control focus without storing DOM nodes in state.”
  4. Typing: “On change, I sanitize the value, update that index, and move focus forward.”
  5. Backspace: “If the current input has a value, I clear it. If it is already empty, I clear the previous digit and focus the previous input.”
  6. Paste: “I prevent the browser's default paste behavior, extract digits, distribute them across the array, and update state once.”
  7. Validation: “On submit, I check for empty positions and then join the digits to create the final OTP string.”
  8. Accessibility/mobile: “I add labels, numeric input mode, and one-time-code autocomplete to improve the experience.”
Strong closing line: “The important design decision is separating value management in React state from focus management through refs.”
Debugging

Common Developer Mistakes

MistakeWhy it is a problemBetter approach
Using one string without indexesHarder to manage individual boxes and focus.Use an array with one value per input.
Directly changing state arrayReact may not detect the update correctly.Create a copy: const next = [...otp].
Using document.querySelector for focusCouples component logic to global DOM.Use useRef for input elements.
Not limiting to one digitA user can type multiple characters into one box.Use maxLength={1} plus sanitization.
Allowing letters/symbolsOTP should normally contain digits only.Sanitize with a numeric check or regex.
Backspace only clears current boxUsers expect Backspace to navigate backward.If empty, clear/focus previous box.
No paste handlingUsers often copy OTPs from SMS/email.Handle onPaste and distribute digits.
Submitting incomplete OTPCreates unnecessary API calls.Validate all positions before API call.
Focus changes inside stateFocus is DOM behavior, not application data.Keep focus in refs.
Forgetting accessibilityScreen readers and mobile users may struggle.Add aria-label, inputMode, and autocomplete.
Edge Cases

What should I test?

  • Type one digit in each box.
  • Type a letter — it should be ignored.
  • Type a long value — only one digit should remain.
  • Press Backspace on a filled box.
  • Press Backspace on an empty box.
  • Press ArrowLeft / ArrowRight.
  • Paste a complete 6-digit OTP.
  • Paste text containing letters and digits.
  • Paste more digits than the configured length.
  • Submit with missing digits.
  • Submit a complete OTP.
  • Change OTP length from 6 to another value.

Quick Recap

Remember these 7 points

1. Array state → values
2. useRef → focus
3. onChange → digit
4. Backspace → previous
5. Paste → distribute
6. Validation → complete
7. join("") → final OTP
