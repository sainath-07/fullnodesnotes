Fact 1: What is the Event Loop?

Code Example
console.log('Start');
setTimeout(()=>console.log('Timer'),0);
console.log('End');
Explanation

The Event Loop continuously checks whether the Call Stack is empty. If it is, it moves ready callbacks from queues to the Call Stack.

Interview Question
Output?
Expected Answer
Start End Timer

Fact 2: Call Stack

Code Example
function a(){ b(); }
function b(){ console.log('Hi'); }
a();
Explanation

JavaScript executes one function at a time on a single Call Stack.

Interview Question
Can two JavaScript functions execute simultaneously on the main thread?
Expected Answer
No.

Fact 3: libuv

Code Example
fs.readFile('file.txt',()=>{
 console.log('Done');
});
Explanation

libuv is the C library that provides the Event Loop, asynchronous I/O and a worker thread pool.

Interview Question
What tasks use libuv?
Expected Answer
File system, DNS, crypto and compression.

Fact 4: Thread Pool

Code Example
crypto.pbkdf2(...);
fs.readFile(...);
Explanation

Heavy asynchronous tasks are delegated to libuv's worker thread pool (default size: 4).

Interview Question
How do you increase it?
Expected Answer
Set UV_THREADPOOL_SIZE.

Fact 5: Microtasks vs Macrotasks

Code Example
Promise.resolve().then(()=>console.log('Promise'));
setTimeout(()=>console.log('Timer'),0);
Explanation

Microtasks (Promises, queueMicrotask) run before macrotasks (setTimeout, setInterval).

Interview Question
Which runs first?
Expected Answer
Promise callback.

Fact 6: process.nextTick()

Code Example
process.nextTick(()=>console.log('nextTick'));
Promise.resolve().then(()=>console.log('Promise'));
Explanation

nextTick callbacks execute before Promise microtasks in Node.js.

Interview Question
Which runs first?
Expected Answer
process.nextTick().

Fact 7: setImmediate()

Code Example
setImmediate(()=>console.log('Immediate'));
setTimeout(()=>console.log('Timeout'),0);
Explanation

setImmediate() runs in the Check phase. setTimeout() runs in the Timers phase.

Interview Question
Are they always ordered the same?
Expected Answer
No, it depends on context.

Fact 8: Blocking Code

Code Example
while(true){}
// Server freezes
Explanation

Long synchronous work blocks the Event Loop and delays every request.

Interview Question
Why avoid readFileSync() in APIs?
Expected Answer
It blocks the Event Loop.

Fact 9: Event Loop Phases

Code Example
Timers → Pending → Idle → Poll → Check → Close
Explanation

Callbacks move through Event Loop phases before execution.

Interview Question
Which phase executes setImmediate()?
Expected Answer
Check.

Fact 10: Best Practice

Code Example
await Promise.all([getUsers(), getOrders()]);
Explanation

Use asynchronous APIs, avoid blocking code, and parallelize independent work.

Interview Question
Why is Promise.all() faster?
Expected Answer
Independent tasks run concurrently.

Quick Revision

  • JavaScript runs on one main thread.
  • libuv provides the Event Loop and worker thread pool.
  • Promises run before setTimeout callbacks.
  • process.nextTick() runs before Promise callbacks.
  • Avoid blocking synchronous operations in API servers.
  • Use Promise.all() for independent async tasks.
