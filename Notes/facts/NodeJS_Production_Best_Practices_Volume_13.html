Practice 1: Use Environment Variables

Code Example
PORT=3000
SECRET_KEY=mySecret
Explanation

Store configuration outside source code using .env.

Interview Question
Why use environment variables?
Expected Answer
To avoid hardcoding secrets.

Practice 2: Run with a Process Manager

Code Example
pm2 start index.js
Explanation

PM2 restarts crashed apps and manages production processes.

Interview Question
Why use PM2?
Expected Answer
Automatic restart and monitoring.

Practice 3: Use a Reverse Proxy

Code Example
Nginx -> Node.js
Explanation

Use Nginx to handle SSL, compression and load balancing.

Interview Question
Why use Nginx?
Expected Answer
Improves security and scalability.

Practice 4: Enable HTTPS

Code Example
https.createServer(options, app);
Explanation

Encrypt all communication with TLS.

Interview Question
Why HTTPS?
Expected Answer
Protects data in transit.

Practice 5: Centralized Error Handling

Code Example
app.use(errorHandler);
Explanation

Keep one global error handler for consistent API responses.

Interview Question
Why use a global error handler?
Expected Answer
Cleaner and reusable error handling.

Practice 6: Structured Logging

Code Example
console.error(err);
// or Winston/Pino
Explanation

Log requests and errors for debugging.

Interview Question
Why log errors?
Expected Answer
To diagnose production issues.

Practice 7: Health Check Endpoint

Code Example
app.get('/health',(req,res)=>res.send('OK'));
Explanation

Health checks help load balancers determine service status.

Interview Question
Why create /health?
Expected Answer
To verify the application is running.

Practice 8: Graceful Shutdown

Code Example
process.on('SIGTERM',()=>server.close());
Explanation

Finish active requests before shutting down.

Interview Question
Why graceful shutdown?
Expected Answer
Avoid interrupted requests.

Practice 9: Connection Pooling

Code Example
mongoose.connect(uri,{maxPoolSize:10});
Explanation

Reuse database connections for better performance.

Interview Question
Why connection pooling?
Expected Answer
Reduces connection overhead.

Practice 10: Pagination

Code Example
User.find().skip(0).limit(10);
Explanation

Never return thousands of records in one response.

Interview Question
Why paginate?
Expected Answer
Improves performance and memory usage.

Practice 11: Caching

Code Example
const cache=new Map();
Explanation

Reduce repeated database queries with caching.

Interview Question
Why cache?
Expected Answer
Faster responses and lower DB load.

Practice 12: Production Checklist

Code Example
HTTPS
PM2
Nginx
.env
Logging
Explanation

Combine multiple best practices for reliability, security and performance.

Interview Question
Name three production best practices.
Expected Answer
HTTPS, PM2 and environment variables.

Quick Revision

  • Store secrets in .env.
  • Use PM2 to manage Node.js processes.
  • Place Nginx in front of Node.js.
  • Always enable HTTPS.
  • Implement centralized error handling and structured logging.
  • Create a /health endpoint.
  • Support graceful shutdown.
  • Use connection pooling, pagination and caching.
