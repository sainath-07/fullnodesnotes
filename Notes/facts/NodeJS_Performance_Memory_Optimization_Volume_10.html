Topic 1: Avoid Blocking the Event Loop

Code Example
// Bad
fs.readFileSync('large.txt');

// Good
await fs.promises.readFile('large.txt');
Explanation

Synchronous APIs block the Event Loop. Prefer asynchronous APIs in servers.

Interview Question
Why avoid readFileSync() in APIs?
Expected Answer
It blocks all incoming requests.

Topic 2: Use Streams for Large Files

Code Example
fs.createReadStream('movie.mp4')
  .pipe(res);
Explanation

Streams process files in chunks, reducing memory usage.

Interview Question
Why are streams memory efficient?
Expected Answer
They don't load the whole file into memory.

Topic 3: Promise.all()

Code Example
await Promise.all([
  getUsers(),
  getOrders()
]);
Explanation

Run independent asynchronous operations concurrently.

Interview Question
When should Promise.all() be used?
Expected Answer
When async tasks don't depend on each other.

Topic 4: Use lean() in Mongoose

Code Example
const users = await User.find().lean();
Explanation

lean() skips Mongoose document creation, improving read performance.

Interview Question
Why use lean()?
Expected Answer
Faster read-only queries.

Topic 5: Select Required Fields

Code Example
await User.find().select('name email');
Explanation

Fetch only required fields to reduce network and memory usage.

Interview Question
Why use select()?
Expected Answer
To reduce payload size.

Topic 6: Indexes

Code Example
schema.index({ email: 1 });
Explanation

Indexes speed up reads but slightly slow writes.

Interview Question
Why create indexes?
Expected Answer
To optimize query performance.

Topic 7: Avoid Memory Leaks

Code Example
users = null;
clearInterval(timer);
Explanation

Release unused references and clear timers/listeners.

Interview Question
What causes memory leaks?
Expected Answer
Unused references and unremoved listeners.

Topic 8: Worker Threads

Code Example
import { Worker } from 'worker_threads';
Explanation

Use Worker Threads for CPU-intensive work instead of blocking the Event Loop.

Interview Question
When should Worker Threads be used?
Expected Answer
For CPU-heavy tasks.

Topic 9: Caching

Code Example
const cache = new Map();
Explanation

Cache frequently requested data to reduce database calls.

Interview Question
Why cache data?
Expected Answer
To improve response time.

Topic 10: Compression

Code Example
app.use(compression());
Explanation

Compress responses to reduce bandwidth and improve load times.

Interview Question
Why use compression middleware?
Expected Answer
To send smaller responses.

Topic 11: Connection Pooling

Code Example
mongoose.connect(uri,{ maxPoolSize:10 });
Explanation

Reuse database connections instead of creating a new one for every request.

Interview Question
Why use connection pooling?
Expected Answer
To improve database performance.

Topic 12: Performance Best Practices

Code Example
return res.status(200).json(data);
Explanation

Profile your app, avoid unnecessary work, paginate results, and monitor memory usage.

Interview Question
What is one easy optimization?
Expected Answer
Return only the data clients need.

Quick Revision

  • Use asynchronous APIs instead of synchronous ones.
  • Prefer streams for large files.
  • Use Promise.all() for independent async tasks.
  • Use lean() and select() for faster MongoDB reads.
  • Create indexes for frequently queried fields.
  • Prevent memory leaks by clearing timers and listeners.
  • Use Worker Threads for CPU-intensive work.
  • Cache frequently accessed data.
  • Enable response compression.
  • Use database connection pooling.
