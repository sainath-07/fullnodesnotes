Topic 1: What is a Stream?

Code Example
const stream = fs.createReadStream('video.mp4');
Explanation

Streams process data piece by piece (chunks) instead of loading the entire file into memory.

Interview Question
What is a stream?
Expected Answer
A way to process data incrementally.

Topic 2: Why Streams?

Code Example
fs.createReadStream('large.zip');
Explanation

Streams reduce memory usage and are ideal for large files.

Interview Question
Why use streams?
Expected Answer
To improve memory efficiency.

Topic 3: Readable Stream

Code Example
const rs = fs.createReadStream('input.txt');
Explanation

Readable streams allow you to consume data.

Interview Question
What is a readable stream?
Expected Answer
A stream you can read from.

Topic 4: Writable Stream

Code Example
const ws = fs.createWriteStream('output.txt');
Explanation

Writable streams receive and write data.

Interview Question
What is a writable stream?
Expected Answer
A stream you can write to.

Topic 5: pipe()

Code Example
fs.createReadStream('a.txt')
  .pipe(fs.createWriteStream('b.txt'));
Explanation

pipe() connects streams and automatically manages flow.

Interview Question
What does pipe() do?
Expected Answer
Transfers data between streams.

Topic 6: Backpressure

Code Example
readable.pipe(writable);
Explanation

Backpressure prevents a fast producer from overwhelming a slow consumer.

Interview Question
What is backpressure?
Expected Answer
Flow control between streams.

Topic 7: Buffer

Code Example
const buf = Buffer.from('Hello');
Explanation

A Buffer stores raw binary data outside the V8 heap.

Interview Question
What is a Buffer?
Expected Answer
A container for binary data.

Topic 8: Buffer vs String

Code Example
console.log(Buffer.from('Hi'));
console.log('Hi');
Explanation

Strings are text. Buffers store raw bytes.

Interview Question
When should you use Buffer?
Expected Answer
For binary data like files or images.

Topic 9: Events

Code Example
stream.on('data',chunk=>{});
stream.on('end',()=>{});
Explanation

Streams emit events such as data, end, error and close.

Interview Question
Which events are common on streams?
Expected Answer
data, end, error, close.

Topic 10: Best Practices

Code Example
stream.on('error',err=>console.error(err));
Explanation

Always handle stream errors and prefer streams for large files.

Interview Question
What is a stream best practice?
Expected Answer
Handle errors and avoid readFile() for huge files.

Quick Revision

  • Streams process data in chunks.
  • Use streams for large files to reduce memory usage.
  • pipe() connects streams and manages flow automatically.
  • Backpressure prevents memory overload.
  • Buffers store binary data.
  • Always listen for error events on streams.
