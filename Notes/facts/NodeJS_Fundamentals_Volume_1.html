🚀 Node.js Hidden Facts Handbook

Volume 1 — Node.js Fundamentals

Goal: Learn the core concepts that experienced interviewers often ask beyond basic syntax.

Fact 1

Node.js is a JavaScript runtime, not a framework.
Code Example
console.log(process.version);
Explanation

It runs JavaScript outside the browser using Google's V8 engine.

Interview Question
What is Node.js? Framework or runtime?
Expected Answer
Node.js is a JavaScript runtime built on the V8 engine.

Fact 2

Node.js uses the V8 Engine.
Code Example
console.log(process.versions.v8);
Explanation

V8 compiles JavaScript into machine code for high performance.

Interview Question
Which JavaScript engine does Node.js use?
Expected Answer
V8.

Fact 3

Node.js is single-threaded for JavaScript execution.
Code Example
console.log('Main Thread');
Explanation

Only one JavaScript thread executes code, while async work is delegated to libuv.

Interview Question
How can Node.js handle many users with one thread?
Expected Answer
Using the Event Loop and libuv.

Fact 4

Node.js is event-driven.
Code Example
const EventEmitter = require('events');
Explanation

Events trigger callbacks when work completes.

Interview Question
What does event-driven mean?
Expected Answer
Code reacts to events instead of constant polling.

Fact 5

Node.js is non-blocking by default.
Code Example
fs.readFile('a.txt',()=>{});
Explanation

Async APIs allow the server to continue handling other requests.

Interview Question
Why is Node.js good for APIs?
Expected Answer
Because non-blocking I/O improves concurrency.

Fact 6

Modules are cached after first import.
Code Example
import './user.js';
import './user.js';
Explanation

The file executes only once and is reused.

Interview Question
Why is importing the same module fast?
Expected Answer
Because Node caches modules.

Fact 7

process.env values are strings.
Code Example
console.log(typeof process.env.PORT);
Explanation

Convert values to numbers or booleans if needed.

Interview Question
What is typeof process.env.PORT?
Expected Answer
string

Fact 8

Headers are lowercase.
Code Example
req.headers.authorization;
Explanation

Node normalizes HTTP header names to lowercase.

Interview Question
Why does req.headers.Authorization fail?
Expected Answer
Because Node stores header names in lowercase.

Fact 9

The Event Loop executes callbacks.
Code Example
setTimeout(()=>console.log('done'),0);
Explanation

Timers wait until the call stack is empty.

Interview Question
Does setTimeout(0) run immediately?
Expected Answer
No, it runs after the current call stack.

Fact 10

Node.js is best for I/O-bound work.
Code Example
app.get('/users',handler);
Explanation

Networking, APIs and file operations are ideal workloads.

Interview Question
Is Node suitable for heavy CPU calculations?
Expected Answer
Prefer Worker Threads for CPU-intensive tasks.
