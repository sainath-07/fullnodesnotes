🚀 50 Out-of-the-Box Node.js Interview Questions

Questions commonly asked by experienced backend interviewers.

These questions focus on Node.js internals, Express.js behavior, MongoDB, JWT, Streams, performance, security, and production practices.
#Interview QuestionExpected Short Answer
1Why does req.headers.Authorization return undefined?Node converts header names to lowercase.
2Why does find() return [] while findOne() returns null?find() always returns an array; findOne() returns one document or null.
3Why does bcrypt generate a different hash every time?It uses a random salt.
4Why is JWT encoded instead of encrypted?JWT is designed for integrity, not confidentiality.
5Why shouldn't you use readFileSync() in APIs?It blocks the Event Loop.
6What happens if next() isn't called?The request hangs unless a response is sent.
7Why is express.json() required?It parses JSON request bodies.
8Why does route order matter?Express matches routes in declaration order.
9Difference between app.use() and app.get()?app.use() registers middleware; app.get() registers GET routes.
10Why use return res.json()?To stop further execution.
11Difference between authentication and authorization?Identity vs permissions.
12What is libuv?Library providing Event Loop and async I/O.
13Why is Node.js good for I/O but not CPU work?CPU work blocks the Event Loop.
14When should Worker Threads be used?For CPU-intensive tasks.
15Difference between Worker Threads and Cluster?Threads vs processes.
16Why use Promise.all()?Run independent async operations concurrently.
17What is backpressure?Flow control between streams.
18Why use createReadStream()?Memory-efficient processing.
19Difference between Buffer and String?Binary data vs text.
20Why use lean() in Mongoose?Faster read-only queries.
21Does unique validate duplicates?No, it creates an index.
22What does populate() do?Loads referenced documents.
23Why use indexes?Speed up queries.
24What is ObjectId?MongoDB's default unique identifier.
25Why use path.join()?Cross-platform paths.
26Difference between readFile and createReadStream?Entire file vs chunks.
27What is process.env?Environment variables.
28Why store secrets in .env?Avoid hardcoding.
29Why use HTTPS?Encrypts data in transit.
30What is Keep-Alive?Reuses TCP connections.
31Difference between 401 and 403?Unauthenticated vs unauthorized.
32When use 204?Successful request with no response body.
33Why use PM2?Process management.
34Why use Nginx?Reverse proxy and load balancing.
35What causes 'Cannot set headers after they are sent'?Sending multiple responses.
36What is next(err)?Transfers control to error middleware.
37Why use bcrypt.compare()?Compare plain password with hash.
38Why set JWT expiration?Limit token lifetime.
39What belongs in JWT payload?Non-sensitive claims only.
40Why use rate limiting?Prevent abuse.
41Why disable x-powered-by?Hide framework details.
42What is graceful shutdown?Finish active requests before exit.
43Why use connection pooling?Reuse DB connections.
44What is Event Loop?Coordinates async callbacks.
45Difference between setTimeout and setImmediate?Different Event Loop phases.
46Why can setTimeout(0) be delayed?Waits until call stack is clear.
47What is process.nextTick()?Runs before Promise microtasks.
48Why clear intervals/listeners?Prevent memory leaks.
49Why use caching?Reduce latency and DB load.
50What are streams used for?Large data processing.
Preparation Tips
  • Don't just memorize answers—understand why Node.js behaves this way.
