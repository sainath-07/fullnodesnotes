Topic 1: Authentication vs Authorization

Code Example
// Authentication
POST /login

// Authorization
GET /profile
Explanation

Authentication verifies who the user is. Authorization determines what the authenticated user is allowed to access.

Interview Question
What is the difference between authentication and authorization?
Expected Answer
Authentication verifies identity; authorization checks permissions.

Topic 2: JWT Structure

Code Example
HEADER.PAYLOAD.SIGNATURE
Explanation

A JWT has three Base64URL-encoded parts: Header, Payload and Signature.

Interview Question
What are the three parts of a JWT?
Expected Answer
Header, Payload and Signature.

Topic 3: Generate JWT

Code Example
const token = jwt.sign({ id:user._id }, SECRET_KEY, {
  expiresIn:'1h'
});
Explanation

jwt.sign() creates a signed token using a payload and a secret key.

Interview Question
What does jwt.sign() do?
Expected Answer
It generates a signed JWT token.

Topic 4: Verify JWT

Code Example
const decoded = jwt.verify(token, SECRET_KEY);
Explanation

jwt.verify() validates the signature and decodes the payload.

Interview Question
What happens if the secret key is wrong?
Expected Answer
Token verification fails.

Topic 5: Authorization Header

Code Example
Authorization: Bearer <token>
Explanation

The client sends the JWT in the Authorization header for protected APIs.

Interview Question
Where is the JWT usually sent?
Expected Answer
In the Authorization header as a Bearer token.

Topic 6: Protecting Routes

Code Example
app.get('/profile', authenticate, controller);
Explanation

Authentication middleware verifies the token before allowing access.

Interview Question
Why use authentication middleware?
Expected Answer
To protect private routes.

Topic 7: JWT Payload

Code Example
jwt.sign({ id:user._id, role:'admin' }, SECRET_KEY);
Explanation

Store only non-sensitive data in the payload. Never store passwords or OTPs.

Interview Question
What data should not be stored in a JWT?
Expected Answer
Passwords, OTPs and other sensitive information.

Topic 8: JWT Expiration

Code Example
jwt.sign(payload, SECRET_KEY, {
  expiresIn:'1h'
});
Explanation

Short-lived tokens reduce the impact of a leaked token.

Interview Question
Why set expiresIn?
Expected Answer
To limit the token's lifetime.

Topic 9: Common JWT Errors

Code Example
try {
  jwt.verify(token, SECRET_KEY);
} catch(err) {
  next(err);
}
Explanation

Handle missing, expired and invalid tokens consistently.

Interview Question
What status code is commonly returned for an invalid token?
Expected Answer
401 Unauthorized.

Topic 10: Best Practices

Code Example
// Store secrets in .env
SECRET_KEY=mySecret
Explanation

Keep secrets in environment variables, use HTTPS, validate tokens on every protected request and hash passwords with bcrypt.

Interview Question
What are JWT security best practices?
Expected Answer
Use HTTPS, .env secrets, bcrypt, short expiry and token validation.

Quick Revision

  • Authentication verifies identity; authorization checks permissions.
  • JWT contains Header, Payload and Signature.
  • Generate tokens using jwt.sign().
  • Validate tokens using jwt.verify().
  • Send JWT in the Authorization: Bearer <token> header.
  • Never store sensitive data in the JWT payload.
  • Keep SECRET_KEY in a .env file.
