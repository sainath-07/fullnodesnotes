Topic 1: HTTP Request Lifecycle

Code Example
app.get('/users',(req,res)=>{
  res.json({success:true});
});
Explanation

Client → DNS → TCP Connection → HTTP Request → Express Route → Response → Connection Closed/Kept Alive

Interview Question
Describe the HTTP request lifecycle in Node.js.
Expected Answer
Browser sends a request, Node processes it, and returns a response.

Topic 2: HTTP vs HTTPS

Code Example
import http from 'http';
import https from 'https';
Explanation

HTTPS is HTTP over TLS/SSL. Data is encrypted during transit.

Interview Question
Why is HTTPS more secure than HTTP?
Expected Answer
HTTPS encrypts communication using TLS.

Topic 3: Headers are Lowercase

Code Example
const token = req.headers.authorization;
Explanation

Node normalizes incoming header names to lowercase.

Interview Question
Why is req.headers.Authorization undefined?
Expected Answer
Node stores header names in lowercase.

Topic 4: Keep-Alive

Code Example
res.setHeader('Connection','keep-alive');
Explanation

Keep-Alive reuses TCP connections to improve performance.

Interview Question
What is Keep-Alive?
Expected Answer
It avoids creating a new TCP connection for every request.

Topic 5: Streaming

Code Example
req.pipe(fs.createWriteStream('file.txt'));
Explanation

Node streams data in chunks instead of loading everything into memory.

Interview Question
Why are streams memory efficient?
Expected Answer
They process data chunk by chunk.

Topic 6: Chunked Transfer

Code Example
res.write('Hello ');
res.write('World');
res.end();
Explanation

Data can be sent in multiple chunks before the response ends.

Interview Question
When is chunked transfer useful?
Expected Answer
For large or progressively generated responses.

Topic 7: Status Codes

Code Example
res.status(201).json({message:'Created'});
Explanation

HTTP status codes describe the outcome of the request.

Interview Question
When should you use 201?
Expected Answer
When a new resource is created.

Topic 8: Idempotent Methods

Code Example
GET /users
PUT /users/1
DELETE /users/1
Explanation

GET, PUT and DELETE are idempotent; POST is generally not.

Interview Question
What is an idempotent request?
Expected Answer
Repeating it has the same effect as executing it once.

Topic 9: HTTPS Certificates

Code Example
const options={key:fs.readFileSync('key.pem'),cert:fs.readFileSync('cert.pem')};
Explanation

HTTPS servers use certificates to prove identity and establish encryption.

Interview Question
Why do HTTPS servers need certificates?
Expected Answer
To authenticate the server and enable encrypted communication.

Topic 10: Best Practices

Code Example
app.disable('x-powered-by');
Explanation

Always use HTTPS, validate headers, send proper status codes and avoid exposing server details.

Interview Question
What protocol should production APIs use?
Expected Answer
HTTPS.

Quick Revision

  • HTTP is plaintext; HTTPS uses TLS encryption.
  • Node converts header names to lowercase.
  • Streams process data in chunks.
  • Keep-Alive improves performance by reusing TCP connections.
  • Use proper HTTP status codes.
  • GET, PUT and DELETE are idempotent; POST usually isn't.
