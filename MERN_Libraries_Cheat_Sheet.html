🌍 Global vs Local Installation (Quick Revision)

❓ Why do we install packages globally?

Global installation is used for command-line tools (CLI) that can be used from any Node.js project.

❓ Why are only a few libraries installed globally?

Because only CLI tools need to be available on your computer.
Application libraries should stay inside each project.

Global Installation Local Installation
Installed once on your computer. Installed inside one project.
Can be used in all projects. Can be used only in that project.
Mainly used for CLI Tools. Mainly used for Application Libraries.
✅ Install Globally 
npm i -g nodemon

npm i -g typescript

npm i -g yarn
Why?
  • Command Line Tools
  • Shared across all projects
  • Installed once
📦 Install Locally 
npm i express

npm i mongoose

npm i dotenv

npm i multer

npm i bcryptjs
Why?
  • Project Dependency
  • Stored in node_modules
  • Version controlled by package.json
